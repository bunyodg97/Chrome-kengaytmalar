# 114. Framework versiyasi

> 🇷🇺 Версия фреймворка

Sayt qaysi framework va kutubxonalarda yozilganini, ularning versiyasini va eng so’nggi versiyadan qancha orqada ekanini ko’rsatadi.

## Imkoniyatlar
- React, Next.js, Vue, Nuxt, Angular, Svelte, jQuery, Bootstrap va 40+ boshqa
- Eng so’nggi versiya npm’dan olinadi (24 soat keshlanadi)
- Holat: yangi / kichik yangilanish / major orqada
- Natijani Markdown jadval sifatida nusxalash

## Tezkor tugmalar
Yo’q

## Ruxsatlar va nima uchun kerak
- `activeTab` — Faqat siz tugmani bosgan tabda ishlash
- `scripting` — Sahifani tekshirish uchun skript ishga tushirish
- `storage` — Sozlamalar va ma’lumotlarni brauzerda saqlash
- `https://registry.npmjs.org/*` — eng so’nggi versiyalarni npm reyestridan olish

## O’rnatish (dasturchi rejimi)
1. `python3 scripts/build.py 114` (yoki Releases’dan zip’ni yuklab, oching)
2. `chrome://extensions` → **Developer mode** → **Load unpacked** → `build/114-framework-version`

## Описание
Показывает, на каких фреймворках и библиотеках сделан сайт, их версии и насколько они отстают от последней.

## Возможности
- React, Next.js, Vue, Nuxt, Angular, Svelte, jQuery, Bootstrap и 40+ других
- Последняя версия берётся из npm (кэш 24 часа)
- Статус: актуальна / минорное обновление / отстаёт на мажор
- Копирование результата таблицей Markdown

## Разрешения
- `activeTab` — Работа только во вкладке, где вы нажали кнопку
- `scripting` — Запуск скрипта для проверки страницы
- `storage` — Хранение настроек и данных в браузере
- `https://registry.npmjs.org/*` — получение последних версий из реестра npm
