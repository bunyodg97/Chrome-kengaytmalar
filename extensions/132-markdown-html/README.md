# 132. Markdown → HTML

> 🇷🇺 Markdown → HTML

Markdown yozing — jonli ko’rinish va tayyor HTML kod. GitHub uslubi, kod rang-barangligi, Gmail/Word’ga formatli nusxa, alohida .html fayl.

## Imkoniyatlar
- Jonli ko’rinish, sinxron aylantirish
- GFM: jadvallar, vazifalar ro’yxati, kod bloklari
- Kod bloklarini rang bilan ajratish (190+ til)
- HTML kodni nusxalash yoki formatli matn sifatida (Gmail, Word, Google Docs)
- Uslublari bilan alohida .html fayl yuklab olish
- Matn avtomatik saqlanadi; xavfsiz (DOMPurify)

## Tezkor tugmalar
Yo’q

- `storage` — Sozlamalar va ma’lumotlarni brauzerda saqlash
- `clipboardWrite` — Natijani buferga nusxalash

## Описание
Пишите Markdown — живой предпросмотр и готовый HTML. Стиль GitHub, подсветка кода, копирование с форматированием в Gmail/Word, отдельный .html файл.

## Возможности
- Живой предпросмотр, синхронная прокрутка
- GFM: таблицы, списки задач, блоки кода
- Подсветка кода (190+ языков)
- Копирование HTML-кода или текста с форматированием (Gmail, Word, Google Docs)
- Скачивание отдельного .html файла со стилями
- Текст сохраняется сам; безопасно (DOMPurify)

## Разрешения
- `storage` — Хранение настроек и данных в браузере
- `clipboardWrite` — Копирование результата в буфер
