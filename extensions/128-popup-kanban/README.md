# 128. Popup Kanban

> 🇷🇺 Kanban в popup

Vazifalar uchun kichik Kanban doska brauzer panelida: Rejada, Jarayonda, Tayyor. Sudrab o’tkazish, ranglar, bir nechta doska.

## Imkoniyatlar
- 3 ustun, kartochkalarni sudrab o’tkazish
- Bir nechta doska (loyiha bo’yicha)
- Kartochka rangi (ustuvorlik) va muddat
- Ikki marta bosib tahrirlash
- Ikonkada «Jarayonda» vazifalar soni
- JSON eksport/import, katta oynada ochish

## Tezkor tugmalar
Yo’q

## Ruxsatlar va nima uchun kerak
- `storage` — Sozlamalar va ma’lumotlarni brauzerda saqlash

## O’rnatish (dasturchi rejimi)
1. `python3 scripts/build.py 128` (yoki Releases’dan zip’ni yuklab, oching)
2. `chrome://extensions` → **Developer mode** → **Load unpacked** → `build/128-popup-kanban`

---

## Описание
Мини-доска Kanban в панели браузера: Запланировано, В работе, Готово. Перетаскивание, цвета, несколько досок.

## Возможности
- 3 колонки, перетаскивание карточек
- Несколько досок (по проектам)
- Цвет карточки (приоритет) и срок
- Редактирование двойным кликом
- Число задач «В работе» на иконке
- Экспорт/импорт JSON, открытие в большом окне

## Разрешения
- `storage` — Хранение настроек и данных в браузере
