# 105. Rang ko’rligi simulyatori

> 🇷🇺 Симулятор дальтонизма

Sahifani rang ko’rligining 8 turida ko’ring: protanopiya, deyteranopiya, tritanopiya va boshqalar. Dizayn va kirish qulayligini tekshirish uchun.

## Imkoniyatlar
- Protanopiya, deyteranopiya, tritanopiya, axromatopsiya va ularning yengil shakllari
- Xira ko’rish simulyatsiyasi
- Machado (2009) ilmiy matritsalari
- `Alt+Shift+C` — keyingi turga o’tish

## Tezkor tugmalar
- `Alt+Shift+C` — Keyingi rang ko’rligi turi

## Ruxsatlar va nima uchun kerak
- `activeTab` — Faqat siz tugmani bosgan tabda ishlash
- `scripting` — Sahifani tekshirish uchun skript ishga tushirish
- `storage` — Sozlamalar va ma’lumotlarni brauzerda saqlash

## O’rnatish (dasturchi rejimi)
1. `python3 scripts/build.py 105` (yoki Releases’dan zip’ni yuklab, oching)
2. `chrome://extensions` → **Developer mode** → **Load unpacked** → `build/105-color-blind`

---

## Описание
Смотрите страницу глазами людей с 8 видами нарушения цветовосприятия: протанопия, дейтеранопия, тританопия и др.

## Возможности
- Протанопия, дейтеранопия, тританопия, ахроматопсия и их лёгкие формы
- Симуляция размытого зрения
- Научные матрицы Machado (2009)
- `Alt+Shift+C` — следующий тип

## Разрешения
- `activeTab` — Работа только во вкладке, где вы нажали кнопку
- `scripting` — Запуск скрипта для проверки страницы
- `storage` — Хранение настроек и данных в браузере
