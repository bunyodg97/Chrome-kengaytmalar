# 121. Repo statistikasi

> 🇷🇺 Статистика репозитория

GitHub repozitoriyasi haqida qisqa hisobot: yulduz, fork, ochiq issue va PR, tillar ulushi, faol ishtirokchilar va yillik commit faolligi.

## Imkoniyatlar
- Asosiy ko’rsatkichlar bir qarashda
- Tillar ulushi diagrammasi
- Top-10 ishtirokchi
- 52 haftalik commit faolligi grafigi
- Oxirgi reliz, litsenziya, mavzular
- Repo «tirik»mi — oxirgi push qachon bo’lgani

## Tezkor tugmalar
Yo’q

## Ruxsatlar va nima uchun kerak
- `storage` — Sozlamalar va ma’lumotlarni brauzerda saqlash
- `activeTab` — Faqat siz tugmani bosgan tabda ishlash
- `https://api.github.com/*` — GitHub API’dan statistikani olish

## O’rnatish (dasturchi rejimi)
1. `python3 scripts/build.py 121` (yoki Releases’dan zip’ni yuklab, oching)
2. `chrome://extensions` → **Developer mode** → **Load unpacked** → `build/121-repo-stats`

---

## Описание
Краткий отчёт о репозитории GitHub: звёзды, форки, открытые issue и PR, доли языков, активные участники и активность коммитов за год.

## Возможности
- Основные показатели с первого взгляда
- Диаграмма долей языков
- Топ-10 участников
- График активности коммитов за 52 недели
- Последний релиз, лицензия, темы
- «Жив» ли репо — когда был последний push

## Разрешения
- `storage` — Хранение настроек и данных в браузере
- `activeTab` — Работа только во вкладке, где вы нажали кнопку
- `https://api.github.com/*` — получение статистики из GitHub API
