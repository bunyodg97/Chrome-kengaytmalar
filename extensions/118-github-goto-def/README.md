# 118. GitHub’da «go to definition»

> 🇷🇺 «Go to definition» на GitHub

GitHub’da kod o’qiyotganda Ctrl (Mac’da ⌘) + bosish bilan funksiya, klass yoki o’zgaruvchi e’lon qilingan joyga o’ting — repo ichida qidiradi.

## Imkoniyatlar
- Ctrl/⌘ + bosish — e’lon qilingan joyni repo bo’yicha qidirish
- Ctrl bosib turilganda so’z ostiga chiziq tortiladi
- Belgilangan matn uchun `Alt+Shift+G`
- Popup’dan istalgan nomni qidirish
- Barcha tillar: JS/TS, Python, Go, PHP, Java, C#, Rust…

## Tezkor tugmalar
- `Alt+Shift+G` — Belgilangan nomning e’lonini topish

## Ruxsatlar va nima uchun kerak
- `storage` — Sozlamalar va ma’lumotlarni brauzerda saqlash
- `activeTab` — Faqat siz tugmani bosgan tabda ishlash
- `scripting` — Sahifani tekshirish uchun skript ishga tushirish
- `https://github.com/*` — tarmoq so’rovlari uchun

## O’rnatish (dasturchi rejimi)
1. `python3 scripts/build.py 118` (yoki Releases’dan zip’ni yuklab, oching)
2. `chrome://extensions` → **Developer mode** → **Load unpacked** → `build/118-github-goto-def`

## Описание
Читая код на GitHub, переходите к объявлению функции, класса или переменной по Ctrl (⌘ на Mac) + клик — поиск внутри репозитория.

## Возможности
- Ctrl/⌘ + клик — поиск объявления по репозиторию
- При зажатом Ctrl слово подчёркивается
- `Alt+Shift+G` для выделенного текста
- Поиск любого имени из popup
- Все языки: JS/TS, Python, Go, PHP, Java, C#, Rust…

## Разрешения
- `storage` — Хранение настроек и данных в браузере
- `activeTab` — Работа только во вкладке, где вы нажали кнопку
- `scripting` — Запуск скрипта для проверки страницы
- `https://github.com/*` — для сетевых запросов
