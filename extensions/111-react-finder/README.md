# 111. React komponent topuvchi

> 🇷🇺 Поиск React-компонентов

Sahifadagi elementni bosing — u qaysi React komponentga tegishli, qaysi faylning qaysi qatorida yozilgani va komponentlar zanjirini ko’rsatadi. Bir bosishda VS Code’da ochadi.

## Imkoniyatlar
- Sichqoncha ostidagi element komponenti va fayl:qator
- Komponentlar zanjiri (App › Layout › Button)
- Bosilganda props konsolga chiqadi ($rf), fayl yo’li nusxalanadi
- VS Code, Cursor yoki WebStorm’da ochish
- React 16–19 (fayl manzili development build’da)
- `Alt+Shift+R` — tanlash rejimi

## Tezkor tugmalar
- `Alt+Shift+R` — Komponent tanlash rejimi

## Ruxsatlar va nima uchun kerak
- `activeTab` — Faqat siz tugmani bosgan tabda ishlash
- `scripting` — Sahifani tekshirish uchun skript ishga tushirish
- `storage` — Sozlamalar va ma’lumotlarni brauzerda saqlash

## O’rnatish (dasturchi rejimi)
1. `python3 scripts/build.py 111` (yoki Releases’dan zip’ni yuklab, oching)
2. `chrome://extensions` → **Developer mode** → **Load unpacked** → `build/111-react-finder`

---

## Описание
Наведите на элемент — покажет, какому React-компоненту он принадлежит, в каком файле и строке, и цепочку компонентов. Открывает в VS Code в один клик.

## Возможности
- Компонент и файл:строка элемента под курсором
- Цепочка компонентов (App › Layout › Button)
- По клику props выводятся в консоль ($rf), путь копируется
- Открытие в VS Code, Cursor или WebStorm
- React 16–19 (путь к файлу в development-сборке)
- `Alt+Shift+R` — режим выбора

## Разрешения
- `activeTab` — Работа только во вкладке, где вы нажали кнопку
- `scripting` — Запуск скрипта для проверки страницы
- `storage` — Хранение настроек и данных в браузере
