# 125. Dasturchi uchun yangi tab

> 🇷🇺 Новая вкладка для разработчика

Yangi tabda: ochiq PR’laringiz, sizdan review kutayotganlar, tayinlangan issue’lar, GitHub faolligi, vazifalar ro’yxati va tezkor havolalar.

## Imkoniyatlar
- Mening ochiq PR’larim va review so’rovlari
- Menga tayinlangan issue’lar
- Oxirgi GitHub faolligi
- Vazifalar ro’yxati (brauzerda saqlanadi)
- Tezkor havolalar va qidiruv: Google, GitHub, MDN, StackOverflow, npm
- Soat va sana o’zbek/rus tilida

## Tezkor tugmalar
Yo’q

## Ruxsatlar va nima uchun kerak
- `storage` — Sozlamalar va ma’lumotlarni brauzerda saqlash
- `https://api.github.com/*` — GitHub’dan PR, issue va faollikni olish

## O’rnatish (dasturchi rejimi)
1. `python3 scripts/build.py 125` (yoki Releases’dan zip’ni yuklab, oching)
2. `chrome://extensions` → **Developer mode** → **Load unpacked** → `build/125-dev-newtab`

---

## Описание
На новой вкладке: ваши открытые PR, ожидающие вашего ревью, назначенные issue, активность GitHub, список задач и быстрые ссылки.

## Возможности
- Мои открытые PR и запросы на ревью
- Назначенные мне issue
- Последняя активность GitHub
- Список задач (хранится в браузере)
- Быстрые ссылки и поиск: Google, GitHub, MDN, StackOverflow, npm
- Часы и дата на узбекском/русском

## Разрешения
- `storage` — Хранение настроек и данных в браузере
- `https://api.github.com/*` — получение PR, issue и активности с GitHub
