# 129. CSV va Excel ko’ruvchi

> 🇷🇺 Просмотр CSV и Excel

CSV, TSV va Excel (.xlsx) fayllarni Excel’siz, brauzerning o’zida jadval ko’rinishida oching: saralash, qidiruv, varaqlar, eksport. Fayl hech qayerga yuborilmaydi.

## Imkoniyatlar
- CSV/TSV: ajratgich va kodirovka (UTF-8, Windows-1251) avtomatik aniqlanadi
- XLSX: barcha varaqlar, sanalar to’g’ri ko’rinadi
- Ustun bo’yicha saralash, umumiy qidiruv
- Ustun statistikasi: soni, yig’indi, o’rtacha, min/max
- Filtrlangan natijani CSV qilib saqlash
- Faylni sudrab tashlash; internetsiz ishlaydi

## Tezkor tugmalar
Yo’q

## Ruxsatlar va nima uchun kerak
- `storage` — Sozlamalar va ma’lumotlarni brauzerda saqlash

## O’rnatish (dasturchi rejimi)
1. `python3 scripts/build.py 129` (yoki Releases’dan zip’ni yuklab, oching)
2. `chrome://extensions` → **Developer mode** → **Load unpacked** → `build/129-csv-excel-viewer`

---

## Описание
Открывайте CSV, TSV и Excel (.xlsx) таблицей прямо в браузере без Excel: сортировка, поиск, листы, экспорт. Файл никуда не отправляется.

## Возможности
- CSV/TSV: разделитель и кодировка (UTF-8, Windows-1251) определяются сами
- XLSX: все листы, даты отображаются правильно
- Сортировка по столбцу, общий поиск
- Статистика столбца: количество, сумма, среднее, мин/макс
- Сохранение отфильтрованного результата в CSV
- Перетаскивание файла; работает без интернета

## Разрешения
- `storage` — Хранение настроек и данных в браузере
