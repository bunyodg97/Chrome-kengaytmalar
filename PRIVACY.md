# Maxfiylik siyosati / Политика конфиденциальности

**Dasturchi:** Bunyodg97 — https://www.ali-dasturchi.uz

## O’zbekcha
- Kengaytmalar hech qanday shaxsiy ma’lumotni dasturchiga yubormaydi, analitika va reklama ishlatmaydi.
- Sozlamalar va ma’lumotlar (vazifalar, vaqt yozuvlari, API kalitlar) faqat brauzeringizda (`chrome.storage.local`) saqlanadi.
- Tarmoq so’rovlari faqat kengaytma vazifasi uchun va faqat siz tanlagan manzillarga yuboriladi:
  - GitHub API (`api.github.com`) — GitHub bilan ishlovchi kengaytmalar;
  - npm/PyPI reyestrlari — versiyalarni tekshirish;
  - siz tanlagan AI provayder (Anthropic, OpenAI va h.k.) — AI kengaytmalari, faqat o’z kalitingiz bilan;
  - `ntfy.sh` (Telefon konsoli) va `webhook.site` (Webhook sinovi) — relay xizmatlar; bu xizmatlarga yuborilgan ma’lumot ularning o’z siyosatiga bo’ysunadi.
- Sahifa ichidagi ma’lumotlarni o’qiydigan kengaytmalar uni faqat sizga ko’rsatish uchun ishlatadi.

## Русский
- Расширения не отправляют разработчику никаких личных данных, не используют аналитику и рекламу.
- Настройки и данные (задачи, записи времени, API-ключи) хранятся только в вашем браузере (`chrome.storage.local`).
- Сетевые запросы выполняются только для работы функции и только на выбранные вами адреса:
  - GitHub API (`api.github.com`) — расширения для GitHub;
  - реестры npm/PyPI — проверка версий;
  - выбранный вами AI-провайдер (Anthropic, OpenAI и др.) — AI-расширения, только с вашим ключом;
  - `ntfy.sh` (Консоль телефона) и `webhook.site` (Тест вебхуков) — relay-сервисы; переданные им данные регулируются их собственной политикой.
- Расширения, читающие данные страницы, используют их только для показа вам.
