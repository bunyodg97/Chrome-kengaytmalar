Dasturchilar, traderlar va kundalik hayot uchun **157 ta bepul Chrome kengaytmasi**. Deyarli hammasi **o’zbek va rus tilida** (199–213 hozircha faqat o’zbekcha), Manifest V3. Ma’lumotlaringiz faqat brauzeringizda saqlanadi.

> 🇷🇺 **157 бесплатных расширений Chrome** для разработчиков, трейдеров и повседневной жизни. Почти всё на **узбекском и русском** (199–213 пока только на узбекском), Manifest V3. Ваши данные остаются только в браузере.

Dasturchi: **Bunyodg97** — [ali-dasturchi.uz](https://www.ali-dasturchi.uz) · [❤️ Qo’llab-quvvatlash](https://www.ali-dasturchi.uz/#donat)

📦 **Yuklab olish:** [Releases](https://github.com/bunyodg97/Chrome-kengaytmalar/releases) — har bir kengaytma alohida zip.
🖼 **Katalog (skrinshotlar bilan):** [`catalog/index.html`](catalog/index.html)

## Tez o’rnatish

1. [Releases](https://github.com/bunyodg97/Chrome-kengaytmalar/releases)’dan kerakli zip’ni yuklang.
2. Zip’ni **doimiy papkaga** oching (masalan `C:\Kengaytmalar\`) va keyin ko’chirmang yoki nomini o’zgartirmang — Chrome kengaytmani shu papka manzili bo’yicha eslab qoladi.
3. `chrome://extensions` → **Developer mode** → **Load unpacked** → papkani tanlang.

> Kengaytmalar ID’si doimiy (`manifest.json` ichidagi `key`), shuning uchun papkani ko’chirib qayta qo’shsangiz saqlangan ma’lumotlar yo’qolmaydi.

## Har bir kengaytmadagi «Sozlamalar» bo’limi

- **Til:** O’zbekcha / Русский. Birinchi ochilganda brauzer tiliga qarab o’zi tanlanadi (rus tili bo’lsa — ruscha, aks holda o’zbekcha).
- **Dasturchi:** Bunyodg97 → www.ali-dasturchi.uz
- **❤️ Dasturchini qo’llab-quvvatlash** → www.ali-dasturchi.uz/#donat
- **Boshqa kengaytmalar va dasturlar** havolasi
- **Versiya** va **tezkor tugmalar** ro’yxati (o’zgartirish tugmasi bilan)
- Kerak bo’lsa, kengaytmaning o’z sozlamalari (AI kaliti, GitHub token va h.k.)

Havolalarni o’zgartirish uchun bitta fayl yetarli: [`shared/config.js`](shared/config.js).

```

  strings.js           o'zbekcha va ruscha matnlar
  *.body.html          sahifa tanasi (sarlavha, tablar, Sozlamalar avtomatik qo'shiladi)
  *.js                 kengaytma kodi
  README.md            avtomatik yaratiladi
extensions/_common/    bir nechta kengaytma ishlatadigan kod (kutubxona aniqlagich)
```
